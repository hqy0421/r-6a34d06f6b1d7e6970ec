# 贷款收款与余额勾稽工具（pyexcel 原生 Book）

从来源工作簿的三张 Sheet（当前贷款 / 利率变更 / 收款）生成原生
`pyexcel.Book` 结果文件，包含逐笔收款分配、指定截止日余额、逐日台账与
逐月勾稽。来源文件与旧结果文件一律不改。

## 运行

```bash
# 用 -I 隔离模式运行，避免当前目录/脚本目录中被植入的同名模块
python3 -I loan_reconcile.py <输入工作簿> <输出工作簿> [截止日 YYYY-MM-DD]
# 独立核验（Decimal 重算，不调用引擎计算代码）
python3 -I verify.py <输入工作簿> <结果工作簿> <截止日>
# 生成演示用样例来源工作簿
python3 -I make_sample_workbook.py <样例输出路径>
```

截止日省略时，自动取全部放款日 / 利率生效日 / 收款日中的最大日期。
输出支持 `.xlsx` / `.xlsm` / `.xls` / `.ods`；`.csv/.tsv` 因多 Sheet
会被 pyexcel 拆成目录文件而明确拒绝。输出路径已存在时直接报错，
不会覆盖旧结果。

## 口径（固定，不随跨月、部分还款、结清后多收改变）

| 项目 | 规则 |
|---|---|
| 金额单位 | 整数分；拒绝小数、千分位字符串、布尔 |
| 利率单位 | 整数基点（1 bp = 0.01% 年利率） |
| 计息惯例 | 实际天数 / 365；逐日、按币种独立 ROUND_HALF_UP 取整到分 |
| 日内顺序 | 日初先生效利率变更 → 再按业务序号逐笔收款 → 日终仅对剩余本金计一天息 |
| 收款分配 | 先还已欠利息，再还本金；超出部分进「余款」，单列、不作后续贷项、不抵其它贷款 |
| 欠息处理 | 未付利息不资本化、不计复利；本金清零后不再计息 |
| 放款日 | 当日起息（日终计一天） |

整数版 ROUND_HALF_UP 已与 `Decimal(ROUND_HALF_UP)` 在 10 万组随机数上
验证完全一致。

## 来源 Sheet 列名（按当前表头取数，支持别名、空白与大小写归一）

- 当前贷款：贷款编号、借款人、币种、放款日、本金_分、年利率_基点
- 利率变更：贷款编号、生效日、新年利率_基点
- 收款：贷款编号、收款日、金额_分、业务序号

英文别名（如 `loan_id / principal_cents / rate_bps / payment_date /
amount_cents / seq`）同样可用，完整别名见 `loan_reconcile.py` 顶部。
缺列、表头重名、全空 Sheet 均整次报错。空行自动跳过。

## 结果 Book 的 Sheet

1. 三张来源 Sheet（逐单元格原样保留）
2. 参数与口径 — 截止日、口径说明、现金总量核对
3. 逐笔分配 — 每笔收款的还息/还本/余款及收款后余额，带来源行号
4. 截止日余额 — 剩余本金、已欠利息、余款累计、应收合计
5. 逐日台账 — 每天利率、现金分配、计息、日终三项余额
6. 逐月勾稽 — 三条滚动恒等式与核对结果列
7. 币种月度汇总 — 按币种加总，恒等式在汇总层再次成立
8. 异常与跳过 — 晚于截止日的事件登记（不参与计算）

逐月三条恒等式（输出表自身即可复核）：

- 本金：月初本金 − 当月还本 = 月末本金
- 利息：月初欠息 + 当月计息 − 当月还息 = 月末欠息
- 现金：当月收款 = 当月还息 + 当月还本 + 当月余款

## 整次报错的数据问题（不产生任何输出文件）

重复贷款编号、坏日期/非 ISO 日期、悬空的贷款引用（收款或利率变更指向
不存在的贷款）、同日重复利率变更、同日重复业务序号、非整数金额、
零/负本金、负利率、利率或收款早于放款日、缺 Sheet/缺列、输出路径冲突。

## 目录约定

- 脚本目录：`loan_audit/`（与数据目录分开）
